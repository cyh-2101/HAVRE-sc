# Publication boundary

This public source snapshot was refreshed on 2026-09-08 from the current private
working tree, based on commit f7bb1efb83f4bd1f77805286c38cbf8126c5875f and the
subsequent authorized chat/PWA repairs. The commit alone does not contain every
exported change. The owner explicitly requested this showcase update. It appends
to the existing independently rooted public history; private commits and author
metadata are never merged.

The private archive remains authoritative for exact historical evidence and
owner decisions. This mirror contains source, contracts, migrations, synthetic
fixtures and technical conclusions. It excludes owner databases, private chats,
Memory, feedback, OA case material, per-case new research outputs, credentials,
device origins, personal screenshots, model weights and runtime state.

Detailed owner audits are represented by explicit public technical synopses.
Owner path prefixes are replaced only here. Private OA-specific prompt references
are removed only here. These modified files are not byte-identical to private
canonical artifacts, and hashes quoted by archival documents refer to their
original evidence. One regression containing an exact assistant transcript is
omitted from the public test source and listed in the exclusion registry. No
private test is replaced by invented data or counted as a public pass.

The public verification runner initializes the canonical migrations and role
grants before test discovery, so database-guard results do not depend on an earlier
test class having prepared the role permissions. This is public-clone setup, not
a production policy or schema change. Most code and tests are AI-authored; the
[contribution statement](docs/RESUME_EVIDENCE.md) separates system evidence from
the human contributor's work.

See [current implementation](docs/CURRENT_IMPLEMENTATION.md),
[public testing](docs/PUBLIC_TESTING.md) and
[release audit](docs/PUBLIC_RELEASE_AUDIT.md).
Publication grants no training, promotion, sensing or new delivery authority.
